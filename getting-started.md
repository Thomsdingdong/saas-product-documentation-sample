# Getting Started with TaskFlow

Welcome to **TaskFlow**, a cloud-based task and project management platform designed to help teams organize work, collaborate efficiently, and track project progress.

This guide will help you start using TaskFlow in just a few minutes.

---

# Prerequisites

Before getting started, ensure that you have:

- A valid email address
- Internet access
- A modern web browser (Chrome, Edge, Firefox, or Safari)

No installation is required because TaskFlow is a **web-based SaaS platform**.

---

# Step 1: Create an Account

1. Navigate to the TaskFlow signup page
2. Enter the following information:

- Full name
- Email address
- Password

3. Click **Create Account**

After registration, you will be redirected to the **TaskFlow dashboard**.

---

# Step 2: Create Your First Project

Projects help organize tasks related to a specific goal or initiative.

To create a project:

1. Open the **Dashboard**
2. Click **Create Project**
3. Enter:

- Project Name
- Description
- Deadline (optional)

4. Click **Create**

Your project will now appear in the **Projects list**.

---

# Step 3: Create Your First Task

Tasks represent individual work items within a project.

To create a task:

1. Open your project
2. Click **Add Task**
3. Fill in the task details:

- Task title
- Description
- Assignee
- Due date
- Priority level

4. Click **Create Task**

The task will now appear in the project task list.

---

# Step 4: Invite Team Members

Collaboration is a core feature of TaskFlow.

To invite teammates:

1. Go to **Workspace Settings**
2. Select **Team Members**
3. Click **Invite Member**
4. Enter the team member's email address
5. Assign a role (Admin or Member)

The invited user will receive an email invitation.

---

# Step 5: Track Progress

Once tasks are created, teams can monitor progress using the **Dashboard**.

The dashboard displays:

- Task completion status
- Active projects
- Team workload
- Project progress overview
