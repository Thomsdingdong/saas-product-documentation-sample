# Release Notes

This document tracks feature releases, improvements, and bug fixes for the TaskFlow platform.

---

# Version 1.2.0
Release Date: June 2025

## New Features

### Task Priority Levels
Users can now assign priority levels to tasks.

Available priorities:
- Low
- Medium
- High
- Urgent

This helps teams better organize and focus on critical tasks.

---

### Team Mentions
Users can mention teammates in task comments using the **@username** format.

**Example:** 
***@alex please review this task before Friday***

Mentioned users will receive a notification.

---

## Improvements

### Dashboard Performance
Improved dashboard loading performance for accounts with large numbers of tasks.

### Notification System
Improved reliability of email notifications for task updates and mentions.

---

## Bug Fixes

- Fixed issue where task comments were not refreshing automatically
- Fixed bug causing incorrect task completion percentages in dashboard
- Resolved occasional login timeout issue

---

# Version 1.1.0
Release Date: April 2025

## New Features

### File Attachments
Users can now upload attachments directly to tasks.

Supported file types include:
- PDF
- PNG
- JPG
- DOCX
- XLSX

Maximum file size: **25 MB**

---

### Project Dashboard
Added project dashboard to provide visual overview of:

- Project progress
- Task completion rate
- Team workload

---

## Improvements

- Improved task search functionality
- Improved system notification delivery

---

## Bug Fixes

- Fixed issue preventing users from editing task descriptions
- Fixed UI alignment issue on smaller screens

# Version 1.0.0
Release Date: February 2025

## Initial Release

The first official release of **TaskFlow** includes the following core features:

### Core Features

- Project creation and management
- Task creation and assignment
- Task status tracking
- Team collaboration through comments
- Basic project dashboard
- User authentication and role management

---

## Known Limitations

- Mobile application not yet available
- Limited third-party integrations

Future updates will introduce additional features and improvements.
