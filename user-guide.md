# User Guide

---

## Introduction

This guide explains how end users can use **TaskFlow** to manage projects, create tasks, collaborate with team members, and track progress.

The instructions in this guide are intended for standard users who have already created an account or have been invited to a workspace.

---

## Accessing TaskFlow

1. Open a web browser.
2. Navigate to the TaskFlow login page.
3. Enter your registered **email address** and **password**.
4. Click **Sign In**.

After successful authentication, the **Dashboard** will be displayed.

---

## Dashboard Overview

The dashboard provides a high-level view of your work activities, including:

- Assigned tasks
- Project progress
- Recent activity
- Notifications

Users can quickly access their tasks and active projects from this page.

---

## Creating a Project

Projects help organize tasks and team collaboration.

### Steps

1. Navigate to the **Projects** section.
2. Click **Create Project**.
3. Enter the following information:
   - Project Name
   - Description (optional)
   - Project Deadline
4. Click **Create**.

The new project will now appear in the project list.

---

## Creating a Task

Tasks represent individual work items within a project.

### Steps

1. Open the desired **Project**.
2. Click **Add Task**.
3. Enter the task details:
   - Task Title
   - Description
   - Assignee
   - Priority Level
   - Due Date
4. Click **Save**.

The task will now be visible in the project task board.

---

## Updating Task Status

TaskFlow allows users to update the status of tasks as work progresses.

Available statuses include:

- **To Do**
- **In Progress**
- **Completed**

### Steps

1. Open the task.
2. Locate the **Status** field.
3. Select the appropriate status.
4. Save the changes.

---

## Collaborating with Team Members

Users can collaborate directly within tasks.

### Available collaboration features

- Comment on tasks
- Mention team members using `@username`
- Upload supporting files or documents
- Receive notifications when tasks are updated

This allows teams to maintain communication within the context of the task.

---

## Managing Notifications

TaskFlow sends notifications for important events such as:

- Task assignment
- Task updates
- Project activity
- Mentions in comments

Notifications appear in the **notification panel** in the top navigation bar.

---

## Logging Out

To securely end your session:

1. Click your **profile icon** in the top-right corner.
2. Select **Log Out**.

Your session will be terminated and you will return to the login page.
